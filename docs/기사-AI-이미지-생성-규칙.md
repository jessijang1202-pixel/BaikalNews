# 기사 대표 이미지 (AI 생성) 규칙

관리자 페이지 기사 작성/편집 화면에서 "자동생성" 버튼으로 프롬프트를 만들고, "AI 이미지 생성" 버튼으로 실제 이미지를 만드는 두 단계로 동작합니다.
관련 코드: `admin/js/admin.js` — `autoGenerateImagePrompt()`, `triggerAiImageGeneration()`, `generateGeminiImage()`

## 1단계 — 프롬프트 자동 생성 (`autoGenerateImagePrompt`)

기사 제목/리드문단/본문을 Gemini 텍스트 모델에 보내 이미지 생성용 한글 프롬프트 한 문단을 받아옵니다. 이때 아래 두 옵션을 함께 지정합니다.

### 톤/분위기 (관리자가 드롭다운에서 선택, "자동"이면 무작위)
- 밝고 역동적인
- 따뜻하고 정감 있는
- 활기찬 현장 분위기
- 차분하고 정돈된
- 시네마틱한
- 흑백 이미지
- 레트로 필름 느낌

각 옵션은 막연한 라벨이 아니라 "맑은 날씨/밝은 빛/색감/분위기"를 구체적으로 풀어쓴 설명으로 프롬프트에 주입됩니다 (라벨만으로는 모델이 자꾸 흐리거나 비 오는 장면을 만들어서, 구체적 묘사로 바꿈).

### 구도/중심 대상 (관리자가 드롭다운에서 선택, "자동"이면 무작위)
- 인물 클로즈업 (얼굴·표정)
- 여러 사람이 함께
- 인물과 배경 함께
- 풍경/장소 중심
- 사물·디테일 중심

### 촬영 디테일 힌트 (매 생성마다 무작위 1개, 톤/구도 안에서 자연스럽게 응용)
한낮의 직사광, 골든아워, 얕은 심도, 낮은 앵글, 와이드샷, 클로즈업, 계절감 있는 맑은 날 풍경, 45도 스냅 구도, 창으로 들어오는 실내광, 높은 곳에서 내려다본 부감 구도 중 하나.

### 프롬프트 작성 지침 (텍스트 모델에게 전달되는 원칙)
- **가장 중요**: 실제 보도 사진을 대신하므로 무조건 사실적으로. 일러스트/디지털아트/컨셉아트/인포그래픽/아이콘/은유적 상징물/매끈한 'AI 그림체' 절대 금지. 실제 인체 비율·손/얼굴 디테일·피부 질감·조명·재질감을 갖춘 포토저널리즘 스타일만.
- **날씨/조명**: 기사 내용이 비·폭설·재해를 직접 다루지 않는 한 항상 맑고 화창한 날씨, 밝은 빛. 비/빗방울/젖은 표면/안개/흐린 하늘/우중충함/어두운 새벽·심야 금지.
- **선명도**: 전체적으로 흐릿/뿌옇게 금지. 주제는 항상 또렷한 초점, 배경 흐림은 주제 강조 용도로만 은은하게.
- 기사와 관련된 구체적이고 현실적인 장소·사물·계절·시간대 하나를 선택해 사실적으로 묘사.
- 인물이 나온다면 얼굴/표정이 살아있는 모습 우선 (뒷모습·실루엣보다 좋음). 실존 인물·유명인과 닮지 않은 가상 인물. 정면 응시보다 자연스러운 스냅 구도.
- 텍스트(문서/종이/서류/손글씨/화면/간판/현수막/라벨 등) 등장 완전 배제 — AI가 그리는 한글 텍스트는 작고 흐릿해도 철자가 틀리게 나오기 때문.

## 2단계 — 실제 이미지 생성 (`generateGeminiImage`)

1단계에서 만든 프롬프트에 아래 4가지 규칙(모든 AI 이미지/영상 생성에 공통 적용)과, 기사 대표 이미지 전용 규칙 1가지를 덧붙여 Gemini 이미지 모델을 호출합니다.

### 공통 규칙 (기사 이미지 · Veo 영상 · 숏폼 이미지컷 모두 공통)
1. **IMAGE_REALISM_RULE (포토리얼리즘 최우선)**: 실제 카메라로 찍은 것처럼. 일러스트/페인팅/3D렌더/AI그림체 금지. 사실적인 해부학적 비율(특히 손·얼굴), 자연스러운 피부 질감, 현실적인 조명/그림자, 자연스럽고 연출되지 않은 다큐멘터리 느낌.
2. **IMAGE_TEXT_LANGUAGE_RULE (텍스트 절대 금지)**: 어떤 언어든 읽을 수 있는 텍스트를 화면에 절대 넣지 않음 (문서/간판/상점/거리표지판/현수막/라벨 등, 작거나 멀거나 일부만 보여도 안됨). 부득이한 경우 한글만, 글자로 알아볼 수 없을 만큼 작고 흐릿하게.
3. **IMAGE_NO_RAIN_RULE (맑은 날씨 기본값)**: 비/빗방울/젖은 표면/안개/실안개/흐린 하늘/우중충한 분위기 회피 (기사 내용이 요구하지 않는 한). 주제는 항상 선명한 초점.
4. **MEDIA_KOREAN_PEOPLE_RULE (한국인 외모 필수)**: 등장인물은 반드시 동아시아/한국인 외모. 서양인·혼혈·모호한 인종 절대 금지. 어떤 언어로도 읽을 수 있는 텍스트 금지(간판/화면/문서/손글씨 등).

### 기사 대표 이미지 전용 규칙
- **IMAGE_ASPECT_RATIO_RULE**: 가로 16:9 와이드 랜드스케이프 구도 (정사각형/세로 금지). 기사 히어로 이미지로 자연스럽도록 상하 여백을 두는 와이드샷 구도를 유도.

## 사용 모델
- Gemini 이미지 생성 모델을 API 키로 자동 탐색해 캐싱 (`resolveGeminiImageModel`, 24시간 캐시). "flash" 계열 모델을 우선 선택.

## 참고
- 생성된 이미지는 Storage에 `ai-` 접두사로 업로드되어, 사이트에서는 기존 16:9 크롭 표시를 유지합니다 (관리자가 직접 업로드한 이미지만 원본 비율 그대로 표시). 관련: `css/pages.css`의 `.article-featured-image img[src*="/upload-"]`.
