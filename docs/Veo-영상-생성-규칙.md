# 숏폼 전반부(0:00~0:08) Veo 영상 생성 규칙

숏폼(쇼츠) 마법사에서 대본 생성 시 함께 만들어지는 "Veo 프롬프트"로, 실제 8초 영상을 만드는 규칙입니다.
관련 코드: `admin/js/admin.js` — `generateShortsScript()` (프롬프트 작성), `generateVeoVideo()` (실제 영상 생성 호출)

## 1단계 — 프롬프트 작성 (대본 생성 시 함께 요청)

기사 대본을 생성할 때, Gemini 텍스트 모델에게 대본(JSON)과 함께 `veoPrompt` 필드도 같이 요청합니다.

- 관리자가 이미 전반부용 영상/사진을 업로드해 둔 경우: Veo를 아예 호출하지 않고 업로드 자료를 그대로 사용 (`veoPrompt`는 빈 문자열로 반환하도록 지시).
- 업로드가 없는 경우: **"실사 다큐멘터리/기록영상 톤의 8초 연속 장면 하나"**를 한글 프롬프트로 작성하도록 지시. 카메라 움직임, 장소, 분위기를 구체적으로 묘사하되 일러스트/애니메이션 스타일은 피하도록 명시.
- 0:00~0:03 구간에서 시청자의 스크롤을 멈추게 할 강력한 후킹(hook) 장면을 포함하도록 요청 (전반이 업로드 자료로 대체되어도 후킹 자막 자체는 화면에 그대로 표시됨).
- 사람이 등장하면 반드시 한국인/동양인 외모로 묘사, 외국인·서양인·혼혈로 보이는 인물 금지.
- 휴대폰 화면, 간판, 문서, 자막 등 화면에 텍스트가 등장하는 장면은 언어와 상관없이 절대 만들지 않도록 지시 (AI가 그리는 텍스트는 한글도 철자가 틀리게 나오기 때문).

## 2단계 — 실제 영상 생성 (`generateVeoVideo`)

1단계에서 받은 `veoPrompt`에 아래 규칙을 덧붙여 Veo 모델을 호출합니다.

- **MEDIA_KOREAN_PEOPLE_RULE** (기사 이미지·이미지컷과 공통): 등장인물은 반드시 동아시아/한국인 외모, 서양인·혼혈·모호한 인종 절대 금지. 어떤 언어로도 읽을 수 있는 텍스트(간판/화면/문서/손글씨 등) 절대 금지.

### 생성 파라미터
- `aspectRatio: "9:16"` (세로형 숏폼 규격)
- `durationSeconds: 8`
- 모델: API 키에서 사용 가능한 Veo 모델을 자동 탐색해 캐싱 (`resolveVeoModel`, 24시간 캐시), `veo-3` 계열을 우선 선택. Veo는 이미지 생성용 Gemini 키와 별도로 결제/권한 활성화가 필요할 수 있음.
- 비동기 장기 작업(`predictLongRunning`)으로 시작해 10초 간격, 최대 60회(10분)까지 폴링하여 완료를 기다림.

## 참고
- 기사 대표 이미지에 적용되는 IMAGE_REALISM_RULE / IMAGE_TEXT_LANGUAGE_RULE / IMAGE_NO_RAIN_RULE은 Veo 호출 시점에는 별도로 붙지 않습니다 (해당 내용은 1단계 프롬프트 작성 지침에 "다큐멘터리 톤", "텍스트 금지" 형태로 이미 녹아 있음). 공통으로 강제 적용되는 것은 MEDIA_KOREAN_PEOPLE_RULE뿐입니다.
- 관리자가 나레이션 속도(1.1~1.2배)와 "이미지 컷 1초씩 늘리기"로 최종 30초 타임라인 길이를 조절하지만, Veo 전반부 자체는 항상 8초 고정입니다.
