# 숏폼 후반부(0:08~0:30) 이미지 컷 생성 규칙

숏폼(쇼츠) 마법사의 후반부 22초를 채우는 정지 이미지 컷(기본 5컷)을 만드는 규칙입니다.
관련 코드: `admin/js/admin.js` — `generateShortsScript()` (프롬프트 작성), `generateShortsMedia()` / `generateShortsCutImagesOnly()` (실제 이미지 생성 호출)

## 1단계 — 프롬프트 작성 (대본 생성 시 함께 요청)

기사 대본을 생성할 때, Gemini 텍스트 모델에게 `imageCuts` 배열도 함께 요청합니다. 관리자가 이미 업로드해 둔 컷이 있으면 그만큼 개수를 줄여서 요청합니다 (전체 5컷 중 업로드분 제외).

각 컷마다 아래 4가지를 함께 생성하도록 지시:
- **prompt**: 한글 이미지 생성 프롬프트 — **다큐멘터리 사진 스타일, 세로 구도**로 작성하도록 명시.
- **narration**: 나레이션으로 읽을 자연스러운 한 문장 (자막보다 길고 설명적으로). 소리 내어 읽었을 때 컷당 배정 시간(초당 약 4.5 한글 글자 기준) 안팎에 자연스럽게 끝나도록 하는 것이 목표이며, 이는 강제 글자수 제한이 아니라 권장 가이드입니다 (중간에 내용이 끊기지 않는 것이 우선).
- **caption**: 화면에 표시할 한국어 자막 (15자 내외, 짧고 임팩트 있게 — 나레이션 문장 요약이 아니라 별도의 짧은 문구).
- **duration**: 컷당 지속 시간(초, 기본 약 22÷5초 내외).

공통으로 함께 전달되는 지시:
- 사람이 등장하면 반드시 한국인/동양인 외모로 묘사, 외국인·서양인·혼혈 절대 금지.
- 화면에 텍스트(휴대폰 화면/간판/문서/자막 등)가 등장하는 장면은 언어 무관하게 절대 만들지 않도록 지시.

## 2단계 — 실제 이미지 생성 (`generateShortsMedia` / `generateShortsCutImagesOnly`)

1단계 `prompt`를 그대로 쓰지 않고, 아래 문구를 덧붙여 세로 구도를 한 번 더 강제합니다.

```
{컷 prompt}, vertical 9:16 portrait composition, documentary photography style, natural lighting
```

이렇게 완성된 프롬프트를 기사 대표 이미지와 동일한 `generateGeminiImage()` 함수로 전달하며, 그 함수 내부에서 아래 4가지 공통 규칙이 자동으로 덧붙습니다 (기사 이미지·Veo 영상과 공유).

1. **IMAGE_REALISM_RULE**: 실제 카메라로 찍은 것처럼. 일러스트/페인팅/3D렌더/AI그림체 금지. 사실적인 손·얼굴 비율, 피부 질감, 조명/그림자.
2. **IMAGE_TEXT_LANGUAGE_RULE**: 어떤 언어든 읽을 수 있는 텍스트 절대 금지 (문서/간판/화면/라벨 등). 부득이하면 한글만, 알아볼 수 없을 만큼 작고 흐릿하게.
3. **IMAGE_NO_RAIN_RULE**: 비/안개/흐린 하늘/우중충한 분위기 회피 (기사 내용이 요구하지 않는 한). 주제는 항상 선명한 초점.
4. **MEDIA_KOREAN_PEOPLE_RULE**: 등장인물은 반드시 동아시아/한국인 외모, 서양인·혼혈·모호한 인종 금지. 텍스트 절대 금지.

기사 대표 이미지 전용인 **IMAGE_ASPECT_RATIO_RULE(16:9)**은 이미지 컷에는 적용되지 않습니다 — 대신 위 2단계에서 붙이는 `vertical 9:16 portrait composition` 문구로 세로 구도를 지정합니다.

## 사용 모델
- 기사 대표 이미지와 동일한 Gemini 이미지 생성 모델을 사용 (`resolveGeminiImageModel`, "flash" 계열 우선, 24시간 캐시).

## 재생성 시 동작 차이
- **이미지 컷만 생성** (`generateShortsCutImagesOnly`): 이미 이미지가 있는 컷(업로드했거나 이전에 생성된 컷)은 건너뛰고, 비어 있는 컷만 새로 생성 — 이미 잘 나온 컷까지 다시 비용을 들여 재생성하지 않기 위함.
- **Veo 영상 + 이미지 컷 생성** (`generateShortsMedia`, 통합 버튼): 업로드되지 않은 모든 컷을 매번 다시 생성.
